# Manual de Usuario: Gestion de Recursos Humanos

## Proposito del manual

Este manual explica las pantallas principales de Recursos Humanos para gestion de personas, empleados, catalogos, contratos, acciones de personal, solicitudes de contrato, certificaciones financieras y reportes.

Version con imagenes incrustadas directamente:

`docs/manual-recursos-humanos-gestion.html`

## 1. Gestion de personas

La pantalla **Gestion de Personas** funciona como directorio general. Permite consultar personas registradas, buscar por cedula, nombre o correo y revisar indicadores generales.

![Gestion de personas](assets/manuales-rh/rh-01-personas.png)

Use esta pantalla para ubicar una persona antes de revisar su detalle o asociarla a procesos administrativos.

### Formulario: Agregar persona

El formulario de persona permite registrar datos basicos de identificacion y contacto.

![Formulario para agregar persona](assets/manuales-rh/rh-02-form-persona.png)

Antes de crear una persona, verifique que no exista previamente para evitar duplicados.

## 2. Gestion de empleados

La pantalla **Gestion de Empleados** administra la informacion laboral del personal universitario.

![Gestion de empleados](assets/manuales-rh/rh-03-empleados.png)

Permite revisar empleados activos e inactivos, regimen laboral, dependencia, correo, fecha de ingreso y detalle del empleado.

### Formulario: Agregar empleado

El formulario de empleado permite asociar una persona con informacion laboral, dependencia, regimen y datos institucionales.

![Formulario para agregar empleado](assets/manuales-rh/rh-04-form-empleado.png)

Use este formulario cuando una persona ya registrada pasa a formar parte del personal empleado.

## 3. Parametrizacion de catalogos de Recursos Humanos

La pantalla **Parametros de RR.HH.** administra catalogos utilizados por el sistema.

![Parametros de Recursos Humanos](assets/manuales-rh/rh-05-parametros-rh.png)

Los catalogos permiten normalizar tipos de permisos, modalidades, cargos, regimenes, acciones de personal y otros valores usados por los procesos.

### Formulario: Nuevo tipo de referencia

Este formulario crea un nuevo valor de catalogo. Debe seleccionarse la categoria, nombre, descripcion y estado.

![Formulario de parametro de Recursos Humanos](assets/manuales-rh/rh-06-form-parametro-rh.png)

Solo cree un nuevo parametro cuando el valor no exista. Si existe, edite el registro anterior o inactive valores que ya no deban usarse.

## 4. Gestion de contratos

La pantalla **Gestion de Contratos** permite administrar contratos del personal.

![Gestion de contratos](assets/manuales-rh/rh-07-contratos.png)

Incluye filtros, indicadores y listado de contratos. Desde aqui se puede crear un contrato nuevo o revisar contratos existentes.

### Formulario: Nuevo contrato

El formulario de contrato esta organizado por pasos. En el primer paso se selecciona certificacion financiera, regimen, modalidad, persona, departamento, cargo y autoridades relacionadas.

![Formulario de nuevo contrato](assets/manuales-rh/rh-08-form-contrato.png)

Complete cada paso con cuidado, ya que la informacion del contrato se usa en reportes, acciones administrativas y control institucional.

## 5. Acciones de personal

La pantalla **Acciones de Personal** permite registrar y consultar novedades administrativas del empleado.

![Acciones de personal](assets/manuales-rh/rh-09-acciones-personal.png)

Puede buscar por empleado o numero de accion y revisar el estado de cada registro.

### Formulario: Nueva accion de personal

Este formulario permite crear una accion administrativa para un empleado.

![Formulario de nueva accion de personal](assets/manuales-rh/rh-10-form-accion-personal.png)

Use esta opcion para registrar cambios laborales, movimientos, encargos u otras acciones definidas por los catalogos institucionales.

## 6. Solicitud de contrato

La pantalla **Solicitud de Contrato** gestiona requerimientos previos a la elaboracion de contratos.

![Solicitudes de contrato](assets/manuales-rh/rh-11-solicitud-contrato.png)

Permite consultar solicitudes por estado, modalidad, departamento, personas solicitadas y pendientes.

### Formulario: Nueva solicitud

El formulario de nueva solicitud permite registrar modalidad, departamento, numero de personas, observaciones y documentos requeridos.

![Formulario de nueva solicitud de contrato](assets/manuales-rh/rh-12-form-solicitud-contrato.png)

Use esta pantalla antes de crear contratos cuando el proceso requiera una solicitud formal previa.

## 7. Certificacion financiera

La pantalla **Gestion de Certificaciones Financieras** administra certificaciones usadas para respaldar contratos.

![Gestion de certificaciones financieras](assets/manuales-rh/rh-13-certificacion-financiera.png)

Muestra indicadores de certificaciones registradas, aprobadas, pendientes y rechazadas.

### Formulario: Agregar certificacion

El formulario permite registrar una nueva certificacion financiera y adjuntar documentos relacionados.

![Formulario de certificacion financiera](assets/manuales-rh/rh-14-form-certificacion-financiera.png)

Una certificacion aprobada puede ser seleccionada posteriormente en la creacion de contratos.

## 8. Reporte de contratos

El reporte de contratos permite consultar contratos por filtros y descargar resultados.

![Reporte de contratos](assets/manuales-rh/rh-15-reporte-contratos.png)

Use este reporte para auditoria, revision historica o control administrativo.

## 9. Reporte de contratos activos

Este reporte se enfoca en contratos vigentes.

![Reporte de contratos activos](assets/manuales-rh/rh-16-reporte-contratos-activos.png)

Es util para conocer el personal con contrato activo al momento de la consulta.

## 10. Reporte de acciones de personal

Este reporte muestra acciones de personal registradas en el sistema.

![Reporte de acciones de personal](assets/manuales-rh/rh-17-reporte-acciones-personal.png)

Use filtros de empleado, tipo o fecha segun la necesidad del area.

## 11. Reporte de acciones activas

Este reporte muestra acciones vigentes o activas.

![Reporte de acciones activas](assets/manuales-rh/rh-18-reporte-acciones-activas.png)

Permite revisar situaciones administrativas que se encuentran en efecto.

## 12. Reporte historial de empleado

El reporte de historial de empleado consolida informacion historica de una persona.

![Reporte historial de empleado](assets/manuales-rh/rh-19-reporte-historial-empleado.png)

Use este reporte para seguimiento laboral, revision de trayectoria o soporte documental.

## 13. Reporte de solicitudes de contrato

Este reporte permite consultar solicitudes de contrato.

![Reporte de solicitudes de contrato](assets/manuales-rh/rh-20-reporte-solicitudes-contrato.png)

Es util para controlar solicitudes pendientes, aprobadas o atendidas.

## 14. Reporte de certificaciones financieras

Este reporte muestra certificaciones registradas y su estado.

![Reporte de certificaciones financieras](assets/manuales-rh/rh-21-reporte-certificaciones.png)

Use este reporte para controlar certificaciones aprobadas, pendientes o rechazadas.

## 15. Reporte de empleados por departamento

Este reporte agrupa empleados segun departamento o dependencia.

![Reporte empleados por departamento](assets/manuales-rh/rh-22-reporte-empleados-departamento.png)

Permite analizar distribucion de personal por area.

## 16. Reporte resumen de contratos por departamento

Este reporte resume contratos asociados a departamentos.

![Reporte resumen de contratos por departamento](assets/manuales-rh/rh-23-reporte-resumen-contratos-departamento.png)

Use este reporte para analisis institucional y control por dependencia.

## 17. Reporte resumen por horario y contrato

Este reporte relaciona horarios y contratos.

![Reporte resumen por horario y contrato](assets/manuales-rh/rh-24-reporte-resumen-horario-contrato.png)

Es util para revisar distribucion de horarios asociados al personal contratado.

## Recomendaciones

- Verifique personas duplicadas antes de registrar nuevos datos.
- Mantenga actualizados los catalogos de RR.HH.
- Cree contratos usando certificaciones financieras aprobadas.
- Use reportes para validar informacion antes de cierres administrativos.
- No documente ni use pantallas que no carguen correctamente o no tengan datos funcionales.
