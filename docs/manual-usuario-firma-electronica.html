1. Qué permite hacer el módulo

El módulo coordina la firma de un PDF sin trasladar la clave privada ni el PIN del certificado al portal: esos elementos permanecen en FirmaEC y en el dispositivo del firmante.

1

Solicitar firmas

Cargar el PDF, agregar firmantes internos o externos y elegir si firman en cualquier orden o secuencialmente.

2

Firmar con FirmaEC

Revisar el documento, escoger la posición del sello y abrir la aplicación oficial con un enlace temporal.

3

Controlar y validar

Consultar el avance, descargar versiones autorizadas y validar documentos o certificados.

2. Acceso y requisitos

  • Cuenta activa en el Sistema Integrado UTA.
  • Permiso para la opción que se utilizará: bandeja, procesos, firma o validación.
  • Navegador actualizado y acceso a la red institucional cuando corresponda.
  • Aplicación oficial FirmaEC instalada para firmar.
  • Certificado digital vigente y su contraseña/PIN bajo control exclusivo del titular.
Proteja sus credenciales. El portal no necesita conocer la clave privada ni conservar la contraseña del certificado. Nunca envíe el archivo .p12/.pfx ni su contraseña por correo o mensajería.

3. Crear un proceso de firma

Ingrese a Procesos de firma y pulse Nuevo proceso.

  1. Escriba el título. Use un nombre identificable, por ejemplo “Contrato de servicios profesionales 2026”. La descripción se incorporará como contexto en las notificaciones.
  2. Seleccione el PDF original. Solo se admite PDF. Compruebe que sea la versión definitiva antes de enviarlo.
  3. Elija el flujo. En Sin orden todos pueden firmar cuando deseen; en Secuencial el sistema habilita a cada persona según el orden de la lista.
  4. Decida si se notifica al crear. Si desactiva la opción, podrá usar luego “Enviar correo a pendientes” desde el detalle.
  5. Agregue los firmantes. Busque empleados de RH o pulse Firmante externo. Verifique identificación, nombre y correo.
  6. Ordene y revise. En un flujo secuencial, use las flechas para definir el turno. Todos los firmantes deben tener correo.
  7. Pulse Crear proceso de firma. El portal almacena el original, calcula SHA-256 y abre el detalle del proceso.
Importante: después de iniciar el proceso no sustituya el PDF por otra copia. Cada firma genera una versión inmutable enlazada con la anterior.

4. Firmar un documento

Desde un computador

  1. Abra Mi bandeja de firmas y localice el proceso.
  2. Revise el detalle y el PDF. Si su turno está habilitado, pulse Firmar.
  3. Pulse Firmar documento; en el visor, marque la página, posición y tamaño del sello.
  4. Confirme la ubicación. Cuando aparezca el botón independiente, pulse Abrir FirmaEC para firmar. Este segundo clic es intencional: los navegadores bloquean protocolos externos si no proceden de una acción directa.
  5. En FirmaEC seleccione su certificado, ingrese su contraseña/PIN y complete la firma.
  6. Regrese al navegador. La página consulta periódicamente el estado y debe mostrar la firma como completada.

Desde un teléfono o tableta

El inicio también se realiza con el botón explícito Abrir FirmaEC para firmar. La aplicación móvil puede finalizar el PDF sin notificar automáticamente al portal. Si ya aparece “Documento firmado” en FirmaEC y el portal no cambia:

  1. Use Compartir en FirmaEC y guarde el PDF firmado.
  2. Regrese al portal y pulse Subir documento firmado.
  3. Seleccione exactamente el archivo entregado por FirmaEC y espere la validación.
No suba un PDF editado. El sistema verifica estructura, firma, firmante y versión. Si otra persona firmó una versión posterior, una copia antigua será rechazada con conflicto de versión.

5. Flujo para un firmante externo

El firmante recibe por correo un enlace individual. No necesita una cuenta institucional: el enlace contiene una autorización aleatoria de un solo uso asociada exclusivamente a su participación.

  1. Abra el enlace desde el correo de invitación.
  2. Compruebe su nombre, número del proceso y título; visualice o descargue el PDF.
  3. Seleccione la posición del sello y abra FirmaEC, o use el flujo de descarga/compartir/carga cuando firme desde móvil.
  4. Espere el mensaje “Ya firmaste este documento”. El enlace deja de estar disponible al completarse, expirar o cancelarse el proceso.
Vigencia: la invitación se genera con una expiración de 72 horas según la implementación actual. No reenvíe el enlace; si expira, solicite al creador un recordatorio o una nueva coordinación.

6. Seguimiento del proceso

El creador puede abrir un proceso para ver el porcentaje, firmantes, estado individual, versión documental y fechas. Según sus permisos podrá:

Recordar

Enviar correo a quienes siguen pendientes. El envío es asíncrono y tiene reintentos.

Cancelar

Detener un proceso activo. Los enlaces y turnos restantes dejan de estar disponibles.

Descargar

Obtener una versión autorizada. Al completarse, el creador recibe además el documento final por correo.

En flujo secuencial, el próximo firmante pasa a Disponible para firmar solo después de aceptar la versión firmada del participante anterior.

7. Validar documentos y certificados

Validar un PDF firmado

  1. Desde Procesos pulse Validar documento firmado.
  2. Seleccione el PDF.
  3. Revise integridad, número de firmas y los datos de cada firmante que devuelve el sistema.

Validar un certificado

  1. Abra Validar firmas electrónicas desde la opción habilitada en su cuenta.
  2. Seleccione el archivo .p12 o .pfx.
  3. Escriba la contraseña del certificado y pulse Validar certificado.
  4. Revise titular, vigencia y resultado. La contraseña se utiliza durante la operación y no se almacena.

8. Cómo interpretar los estados

EstadoSignificadoQué hacer
En progresoProceso activo; existen firmas pendientes.Esperar, firmar o enviar recordatorio.
Parcialmente firmadoYa existe al menos una firma, pero faltan participantes requeridos.No use copias anteriores del PDF.
Disponible para firmarLa persona puede iniciar su firma ahora.Abrir FirmaEC.
PendienteAsignado, pero puede estar esperando turno secuencial.Consultar el orden.
Firmado / CompletadoParticipación finalizada / todas las firmas requeridas aceptadas.Descargar o cerrar.
RechazadoUn participante rechazó la solicitud.Revisar la causa y crear otro proceso si procede.
CanceladoEl creador detuvo el proceso.No intentar firmar enlaces anteriores.
ExpiradoTerminó el plazo del proceso o de la sesión.Reiniciar la operación o contactar al creador.
Validación fallidaLa firma o documento no superó los controles.No reenviar; comunicar el error al soporte.

9. Problemas frecuentes

SituaciónComprobación y solución
FirmaEC no se abreConfirme que está instalada. Vuelva al portal y use el botón explícito “Abrir FirmaEC para firmar”. Permita al navegador abrir el protocolo externo.
“URL no encontrado y sin autorización”Actualice FirmaEC y comuníquelo a soporte. La versión 5.1.0 comprueba la URL pública de FirmaEC antes de abrir el documento.
Firmé en móvil, pero sigue pendienteGuarde mediante Compartir y use “Subir documento firmado”.
El PDF cargado es rechazadoUse el PDF exacto entregado por FirmaEC. Puede existir una versión posterior o la firma puede corresponder a otra persona.
No aparece el botón FirmarRevise si el flujo es secuencial, si ya firmó, si el proceso expiró/canceló o si no tiene permiso.
No llegó el correoRevise spam y dirección registrada. El creador puede pulsar “Enviar correo a pendientes”; el envío se procesa de manera asíncrona.
Sesión cerrada / 401Inicie sesión nuevamente. No reutilice tokens o enlaces de otra persona.
